# Selected source artwork

These files are the selected generated artwork used to build the final atlas. The magenta extraction background is #FF00FF. Use ../assets/sakiko-v2.png for the actual transparent pet.

canonical-idle.png is the final accepted proportion reference, extracted from the approved idle row. Earlier concept images and rejected revisions are excluded.

animations/ contains each independently generated standard action. look-directions/ contains the four-cardinal reference and two coherent eight-pose look rows. No final look cells were independently spliced or mirrored.

The final atlas was assembled with shared registration, background removal, binary pixel-art alpha, and one edge cleanup pass from the alpha-normalized source. Official character-reference art, temporary upload sessions, local runtime dependencies, and account-specific pet identifiers are excluded.
